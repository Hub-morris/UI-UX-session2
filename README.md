## Topics Covered

### 1. What is Wireframing? Low-fi vs High-fi

A **wireframe** is a simple, skeletal layout of a screen. It shows structure, content placement and functionality, without the visual polish. It lets you test ideas quickly before investing time in detailed design.

| | Low-fidelity (Low-fi) | High-fidelity (High-fi) |
|---|---|---|
| **Look** | Rough boxes, lines, placeholder text, greyscale | Close to the final product: real colors, fonts, images |
| **Purpose** | Explore layout and ideas quickly | Present and validate the near-final design |
| **Speed** | Fast to create and change | Slower, more detailed |
| **Tools** | Paper, whiteboard, Figma | Figma, Adobe XD |
| **When to use** | Early stage, brainstorming | Later stage, before development or user testing |

**Rule of thumb:** start low-fi, get feedback, then move to high-fi.

### 2. User Flow Mapping

A **user flow** is the path a user takes to complete a task in your product, from entry point to goal (for example: *Open app → Sign up → Verify email → Home screen*).

Key points:

- Define the **user's goal** first
- Map each **screen** and **decision point** along the way
- Keep flows simple and remove unnecessary steps
- Use the flow to decide which screens you need to wireframe

### 3. Prototyping in Figma

A **prototype** turns static screens into a clickable, interactive experience so you can see how the product feels before it is built.

In Figma, the basic workflow is:

1. Design your frames (screens)
2. Switch to the **Prototype** tab
3. Connect frames with **interactions** (on click, on hover, etc.)
4. Choose **transitions/animations** (instant, dissolve, move in, smart animate)
5. Press **Play** to preview and share the prototype link

### 4. Interactive Components

Components make designs consistent and reusable. Interactive components go a step further by changing state on interaction, such as:

- Buttons (default, hover, pressed)
- Toggles and checkboxes
- Tabs and dropdown menus
- Navigation bars

Using **variants** and **component states** keeps designs organized and makes prototypes feel realistic.
